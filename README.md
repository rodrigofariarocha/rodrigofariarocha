## Projects

### [MacroMath](https://github.com/rodrigofariarocha/macromath)
Cross-platform nutrition app with AI, now launched. Macro tracking, pantry management, AI-generated meal plans and food recognition from photos.
Started as my final academic project (graded 20/20) and grew into a real product with its own landing page.
`Flutter` `Dart` `Supabase` `Gemini AI` `Astro` `Vercel`

### [RochaCinema](https://github.com/rodrigofariarocha/RochaCinema-EPTD)
Full cinema booking platform with PDF tickets, QR codes, loyalty rewards and an admin dashboard.
Integrated TMDB API for movie metadata and Gemini AI for recommendations.
`ASP.NET Core 9` `C#` `SQL Server` `Entity Framework` `TMDB` `Gemini AI`
